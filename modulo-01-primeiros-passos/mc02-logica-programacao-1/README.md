# MC2 — Lógica de programação I

Tema: **variáveis, tipos e operadores**. Todos os 18 exercícios
abaixo são resolvidos de forma sequencial — sem `if`, sem laço e sem função.
Isso é proposital: o objetivo aqui é dominar entrada/saída, tipos e operadores
antes de introduzir controle de fluxo (isso é o MC3, o próximo microcurso).

## Como estudar

1. Leia o cabeçalho do arquivo (enunciado, entrada, saída esperada).
2. Rode o arquivo como está (`php exercicios/01-ola-nome.php`) pra ver as
   linhas de leitura de entrada já funcionando.
3. Complete a lógica no lugar do `// TODO`.
4. Rode de novo e compare com o exemplo do enunciado.

Materiais de apoio estão listados na nota da trilha (seção do MC2).
