# Gate 1 — Calculadora de console completa

Projeto que fecha o Módulo 1. Bloqueia a passagem para o Módulo 2 até ser
aprovado por Wesley ou George.

## Entrega

CLI em PHP puro com:

- Input do usuário via terminal.
- 3 ou mais condicionais.
- 2 ou mais laços diferentes (ex.: um `for` e um `while`, ou um laço e um
  `switch`/`match` dentro dele).
- Histórico de commits real no Git (não um único "commit final").
- README explicando o que o programa faz e como rodar.

O exercício `menu-calculadora` do MC3 é um bom ponto de partida — mas o Gate
pede uma versão mais completa/robusta do que aquele exercício isolado exige.

## Critérios de avaliação

- Roda sem erro.
- Variáveis com nomes legíveis (nada de `$x1`, `$a2`, `$tmp3`).
- Commits mostram evolução real do raciocínio, não tudo de uma vez.
- O trainee consegue explicar cada trecho do próprio código para o avaliador.

## Como submeter

Abrir Pull Request neste repositório (ou apontar o avaliador para o branch)
quando a calculadora estiver pronta. Sem número máximo de tentativas — se não
passar de primeira, os apontamentos do avaliador entram como próximos passos,
não como reprovação definitiva.
