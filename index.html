Trilha em detalhe

Conteúdo, exercícios de validação e materiais gratuitos de cada item — na mesma ordem do mapa acima.

Fase 1 · Módulo 1 — Primeiros Passos

MC1 — Terminal, Ambiente de Dev e Git essencial 2 semanas

Conteúdo

Linux/terminal básico (pwd, ls, cd, mkdir, touch, rm, cp, mv, cat), redirecionamento e pipes (>, >>, |), permissões (chmod), variáveis de ambiente; instalação PHP + Composer + VS Code; Git/GitHub básico (init, add, commit, clone, push, pull, branch, Pull Request). Resolução de conflito de merge fica no MC16.

Exercícios

Replicar árvore de pastas via terminal; criar/mover/renomear/apagar arquivos via linha de comando; 3+ combinações de pipe/redirecionamento; instalar PHP/Composer e rodar "Hello World" via terminal; repositório Git com 5+ commits atômicos; branch + Pull Request.

Materiais gratuitos
  • Curso de Git e GitHub — Curso em Vídeovídeo · 20h · PT-BR
  • Curso de Linux — Primeiros Passosvídeo · 6h45 · PT-BR
  • O Manual de Comandos do Linux — freeCodeCamptexto · PT-BR
  • Instalação oficial — PHP / Composer / VS Codedocumentação · inglês

Fase 1 · Módulo 1 — Primeiros Passos

MC2 — Lógica de programação I 2 semanas

Conteúdo

Variáveis, tipos de dados, operadores e expressões.

Exercícios

Lista de 15–20 exercícios (Bhaskara, conversor de unidades, médias) em PHP puro via terminal. Pendência: publicar essa lista num repositório Git próprio.

Materiais gratuitos

  • O Manual do PHP — freeCodeCamptexto · PT-BR
  • PHP Manual — Types / Operatorsdocumentação · inglês
  • beecrowd (categoria Iniciante)interativo · PT-BR

Fase 1 · Módulo 1 · Gate

Gate 1 — Calculadora de console completa 1 semana

Entrega

CLI em PHP puro com input do usuário, 3+ condicionais e 2+ laços diferentes, histórico de commits real, README.

Critérios de aceite

Roda sem erro; variáveis legíveis; commits mostram evolução (não um só "commit final"); trainee explica cada trecho do próprio código.

Fase 2 · Módulo 3 — POO e Qualidade (tema ITSM/GLPI)

MC7 — POO em PHP 3 semanas

Conteúdo

Classes, objetos, herança, encapsulamento. Aplicado a um domínio de ITSM/GLPI (Chamado, Fila, Usuário/Técnico, Grupo) — os materiais abaixo são de POO genérica; a contextualização GLPI é adaptação nossa.

Exercícios

Classe abstrata "Chamado" com subclasses "Incidente"/"Requisição" (herança); classe "Fila" gerenciando uma coleção de chamados; "GrupoDeUsuarios"/"Tecnico" com encapsulamento; simular ciclo de status (aberto → em atendimento → resolvido → fechado).

Materiais gratuitos
  • Curso em Vídeo — PHP POO [40h]vídeo · PT-BR
  • PHP Manual — Classes and Objectsdocumentação · inglês
  • PHP Tutorial — PHP OOPtexto · inglês

Fase 2 · Módulo 3 · Gate

Gate 3 — Mini-sistema de abertura de chamados (ITSM) 2 semanas

Entrega

Fase 3 · Módulo 6 · Gate

Gate 6 — Projeto de fechamento da trilha (capstone) 3 semanas

Entrega

Evolução do Gate 5 com suíte de testes automatizados (cobertura mínima a definir, ex.: 60–70% das classes de negócio), Git com histórico de branches/PRs, README completo.

Critérios de aceite

php artisan test passa 100%; app sobe só com o README; defesa oral curta do projeto pro mentor, simulando um code review real.

Formato: autoestudo com material 100% gratuito. Wesley e George (devs sênior) ficam disponíveis para dúvidas e para validar os gates — não ministram aula. Reprovação em gate: feedback específico por escrito + 1 semana extra para corrigir e reapresentar, sem número máximo de tentativas por enquanto. Stack de referência (set/2026): PHP 8.3+ (ref. 8.5), MySQL 8.4/9.7 LTS, Laravel 12/13, PSR-12, PHPUnit.
